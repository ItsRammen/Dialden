# PG titles in automatic channels

Automatic lineups exclude PG and TV-PG titles by default, including titles already approved in the library. Network copies still require a match to their network and era.

To include a title:
1. Open the library's **PG · explicit selection** filter and approve the title if appropriate.
2. Edit the channel, expand **PG exceptions**, search for the title, and select it.
3. Save station changes. Dialden rebuilds the automatic lineup.

Exceptions belong to one channel and survive rescans. They never override library blocks or file availability. A deliberately selected Auto lineup also counts as an explicit choice; remove the title there if you no longer want it.

PG titles awaiting this choice have a separate library view instead of filling the general review queue. Their underlying review decision remains unchanged. Missing or unrecognized ratings still require review.

This change requires updating the server build; no TV app update is needed.
